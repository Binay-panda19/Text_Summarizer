# Text Summarizer

An AI-powered text summarization application that converts long-form content into concise and meaningful summaries.

The project provides a simple web interface where users can paste text, select the desired summary length, and generate a summarized version of the provided content.

---

## Features

- Clean and responsive user interface
- Text input for documents, emails, notes, and other content
- Real-time word and character counter
- Short, medium, and detailed summary options
- Structured summary output
- Copy summary to clipboard
- Clear input and generated summary
- Loading state while generating summaries
- Backend-ready architecture for integrating an NLP/ML summarization model
